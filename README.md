Complete IEEE-standard suite — **SRS** (IEEE 830), **STP** (16 sections, IEEE 829), **STD**, and **STR** — with **123 test cases** across Functional, Non-Functional, API, and Database suites, covering **36 functional + 19 non-functional requirements**. Manual QA on an Israeli e-commerce website (Web). Full **STD** and **STR** documents covering Scope, Test Approach, Environment, and RTM. **65 test scenarios** executed — 48 passed, 15 failed, 2 not run — with defect clusters identified in Search (5 bugs) and Product page / Cart (4 bugs), and a **Conditional Go** release recommendation with Release Notes.
